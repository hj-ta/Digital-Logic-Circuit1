# HW03 - Sequential Logic & FSM

디지털논리회로1 과제로 진행한 Sequential Logic Circuit, Latch, Flip-Flop, Finite State Machine 관련 문제 풀이이다.

## 주요 내용

* SR Latch의 입력 파형에 따른 출력 분석
* Latch와 Flip-Flop의 차이 정리
* 2-bit Multiplier truth table 작성
* Boolean equation 도출 및 회로 설계
* Karnaugh Map과 Quine-McCluskey Method 비교
* Sequence Detector 설계
* Moore Machine / Mealy Machine 상태도 작성
* 상태 전이표(State Transition Table) 작성
* Ring Counter 상태도 및 출력 구조 분석

## 정리

이 과제는 조합논리회로에서 순차논리회로로 확장되는 핵심 개념을 다룬 과제
이전 상태를 저장하고 다음 상태를 결정하는 순차논리의 동작 방식을 FSM 중심으로 정리
